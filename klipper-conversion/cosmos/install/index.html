Install COSMOS

Actively developed

COSMOS is stable enough for everyday printing, but it is still actively developed. Functionality can change between releases, and newer features get less mileage than the rest of the firmware.

Stop: Before you add any plugins

The stock mainboard is extremely resource limited and there is currently very little overhead to run any plugins, packages, or features not in standard klipper/kalico. Do not attempt to install others unless you really know what you are doing!

Installation

Note

Because COSMOS is actively developed, it is important to read the changelogs on GitHub before installing a new version. They may contain additional instructions for migration from an old version.

Online requirement

Your Centauri Carbon must be connected to the internet so the installer can download COSMOS. Choose the Local/Offline method if the printer is not connected to the internet.

  1. Download the latest OpenCentauri installer release.
  2. Insert a FAT32-formatted thumbdrive into your PC.
  3. Extract the install_opencentauri folder from oc-installer.zip onto the root of the thumbdrive.
  4. Eject the thumbdrive from your PC and insert it into your Centauri Carbon.
  5. On your Centauri Carbon, navigate to the files tab, tap Usb Drive, then open the install_opencentauri folder.
  6. Touch and hold the IMPORT_ME_DO_NOT_PRINT file, then tap Import.
  7. In the installer, select Install OpenCentauri > Install COSMOS (Online).
  8. Select Reboot when the installation has finished.
  9. Remove the thumbdrive after COSMOS has booted.
  1. Download the latest OpenCentauri installer release.
  2. Insert a FAT32-formatted thumbdrive into your PC.
  3. Extract the install_opencentauri folder from oc-installer.zip onto the root of the thumbdrive.
  4. Download the latest COSMOS update.swu and place it inside the install_opencentauri folder on your thumbdrive.
  5. Eject the thumbdrive from your PC and insert it into your Centauri Carbon.
  6. On your Centauri Carbon, navigate to the files tab, tap Usb Drive, then open the install_opencentauri folder.
  7. Touch and hold the IMPORT_ME_DO_NOT_PRINT file, then tap Import.
  8. In the installer, select Install OpenCentauri > Install OpenCentauri From USB.
  9. Select Reboot when the installation has finished.
  10. Remove the thumbdrive after COSMOS has booted.

After installation

Connect to the printer's IP address in a web browser to open its web interface. Run CHECK_CALIBRATION from the Macros section, then select Calibrate All. This calibrates resonance compensation, the extruder PID, the load cells, the Z offset, and the bed mesh. If the automatic routine cannot finish, see the manual calibration steps.

Required OrcaSlicer profile

From COSMOS 26.07.0 onwards, the OpenCentauri COSMOS OrcaSlicer profile is required due to changes in the machine start and end G-code. Import and use the latest version of the profile before printing.

Old profiles are rejected

Older machine G-code that calls M729 or M8213 triggers an emergency stop and displays a message telling you to use the COSMOS start and end machine G-code. Update the profile before trying to print again.

Set the printer connection in OrcaSlicer to:

  • Host Type: Moonraker (Klipper)
  • Note: The Moonraker host type lets you select the upload location during a print/upload dialog. Upload to the gcodes folder.
  • Printer Agent: Moonraker
  • Hostname, IP or URL: your printer's IP address

Update

By default, COSMOS checks for updates shortly after startup while the printer is idle. When an update is available, the printer displays an Update Available prompt with an Update Now button. The automatic check and release channel can be changed in cosmos.conf.

  1. Navigate to the settings tab on the printer's screen.
  2. Click Update COSMOS.
  3. Wait for the process to complete.
  1. Log into your printer via SSH.
  2. Run the command update-cosmos
  3. Wait for the process to complete.
  1. Download the latest COSMOS update.swu.
  2. Rename it to emergency.swu
  3. Insert a fat32-formatted thumbdrive into your pc.
  4. Put emergency.swu on the root of the thumbdrive.
  5. Eject your thumbdrive from your pc and insert it into your Centauri Carbon.
  6. Wait for the update process to complete. This should be indicated by an on-screen UI prompt (only appears if Klipper is loaded)

You can also flash an arbitrary .swu via SSH. Just place the .swu somewhere accessible to the machine (like in /user-resource via SCP/SSH), SSH into your machine, then run flash /path/to/.swu.

Uninstall

Warning

Please do not try to flash an official .swu or OpenCentauri patched .swu directly. This will skip downgrading the toolhead/bed and will cause a brick!

  1. Navigate to the settings tab on the printer's screen.
  2. Click Switch to OC Patched.
  3. Wait for the process to complete.
  1. Log into your printer via SSH.
  2. Run the command switch-to-oc-patched
  3. Wait for the process to complete.
